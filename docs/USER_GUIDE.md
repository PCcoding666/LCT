# LCT macOS 使用指南

当前分支使用应用内置翻译引擎。原文字幕不需要翻译模型、Ollama、终端命令或本地服务。

## 首次使用

1. 打开 LCT，点击 **Set Up Captions**。
2. 选择声音来源和实际说话语言。看视频可只选 **System audio**；只有选择 **Microphone** 才需要麦克风权限。
3. 授予语音识别及所选音频来源的系统权限。点击 **Open Captions**。
4. 点击 **start**，播放视频或说话。部分语音语言需要先下载 Apple 的离线资源，应用会在启动字幕时准备。

**语音识别语言必须与声音一致。** 声音电平有变化但没有文字时，先核对语言和语音资源；翻译模型与声音捕获是独立的。

## 可选的本地翻译

进入 **Settings → Local Translation**，点击 **Download Translation Model**。应用内下载 Qwen2.5 1.5B 量化模型，约 1.12 GB；预留至少 1.2 GB 磁盘空间。下载时显示进度，可取消和重试。首次下载需要网络。

完成后打开 **Translate Captions**，选择 **Target Language**，点击 **Done**。已有字幕会保留，新句子在模型就绪后开始翻译。模型下载、加载或推理失败时，原文字幕仍可继续；可在设置或提示中重试。

Apple silicon 使用 Metal，Intel 使用 CPU；实际速度取决于设备和句子长度。语音资源与翻译模型准备好后，识别及翻译在本机执行。字幕是自动识别和生成的结果，可能有误。

## 日常操作

| 操作 | 入口 |
| --- | --- |
| 开始 / 停止 | 底部 start / stop，或 ⌘Space |
| 暂停 / 继续 | 底部暂停按钮，或 ⌘P |
| 修改语言 | 顶部语言菜单，或 Settings |
| 悬浮字幕 | ⌘O |
| 复制 | ⇧⌘C |
| 导出 | 顶部导出菜单，支持 Markdown、Text、SRT |
| 历史 | 顶部时钟按钮，或 ⇧⌘H |

暂停会停止向识别引擎送入音频，继续后沿用当前会话。停止后仍可导出本次字幕；只开原文字幕也能导出。点击垃圾桶会清空当前显示。

历史保存默认关闭。需要保留时，打开 **Settings → Advanced → History → Keep Translation History**；设置保留天数与条目上限。关闭保存不会自动删除已有历史。导出的字幕和诊断文件由你决定是否分享。

## 故障排查

- **没有电平**：确认声音正在播放、音频来源已选中、系统权限已授予；麦克风模式还要选对输入设备。
- **有电平但没有字幕**：确认识别语言匹配，检查语音资源提示；切换语言后重新尝试。
- **只有原文**：这是默认模式。若需要翻译，检查模型下载、Translate Captions 开关及就绪状态。
- **下载失败**：检查当前网络能否访问模型源 Hugging Face，以及剩余磁盘空间，然后重试。应用不会要求安装后台服务。
- **翻译失败或速度慢**：原文字幕可以继续；使用重试，或暂时关闭翻译。长句、较多上下文和 CPU 推理可能增加延迟。

支持 macOS 15 及以上。语音语言可用性受系统和已安装资源影响。开发包、自动化测试通过与公开签名公证发行是不同阶段；请核对下载包的实际发布说明。

问题反馈：[GitHub Issues](https://github.com/PCcoding666/LCT/issues)。开发与验收说明见 [macOS README](../macos/README.md) 和 [测试指南](../macos/TESTING.md)。
